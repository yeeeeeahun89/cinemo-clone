# Cinemo-Clone

## 주요 내용

- 원하는 화면으로 이동할 수 있는 상단 네비게이션 헤더
- 이번 주 주요 영화를 강조하여 보여주는 메인 콘텐츠
- 다양한 추천 영화를 확인할 수 있는 메인 페이지
- 사용자의 프로필과 찜 목록을 확인하고 수정할 수 있는 마이페이지
- 사용자 계정을 변경할 수 있는 프로필 선택 페이지

## 실행 방법

다운로드한 `Cinemo-Clone` 폴더 내부의 `index.html` 파일을 브라우저에서 실행한다.

## 페이지 내 이동 방법

- **메인 페이지:** 상단의 Cinemo 로고 또는 네비게이션의 '홈'을 클릭하면 메인 페이지로 이동한다.
- **마이페이지:** 상단 네비게이션을 통해 마이페이지로 이동할 수 있다.
- **프로필 선택 페이지:** 마이페이지의 '프로필 변경' 버튼을 클릭하면 프로필 선택 페이지로 이동한다.
- **메인 페이지 복귀:** 프로필 선택 페이지에서 프로필 이미지 또는 프로필 이름을 클릭하면 메인 페이지로 이동한다.

## 폴더 구조

Cinemo-Clone/
├── icon/ # 아이콘 파일 폴더
├── imgs/ # 이미지 파일 폴더
├── styles/ # CSS 스타일시트 폴더
│ ├── reset.css # 브라우저 기본 스타일 초기화
│ └── style.css # 페이지 디자인 및 레이아웃 스타일
├── index.html # 메인 페이지
├── mypage.html # 마이페이지
├── profile.html # 프로필 선택 페이지
└── README.md # 프로젝트 안내 문서
